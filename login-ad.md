# What's New: October 2026 Release Notes### New Features* **TrackAbout Web » Records/Assets**: You can now attach documents, such as PDFs, and images to a record or to an individual asset, so you no longer need to store them separately.  * Two new permissions, **attach documents** and **delete documents**, control who can attach and delete documents.  * Files can be JPG, PNG, GIF, or PDF, up to 20 MB.  * A new **Documents and Certificates** list on the Record Detail page shows uploaded documents and automatically generated certificates.  * You can select an option to download all of the documents in a single zip file.* **TrackAbout Web » Production Records**: Production records can now show the total number of assets by product code that were filled in a lot, in addition to the grand totals.  * The **Show Totals by Product Code** on the Production Record setting must be enabled to use this feature. (This setting is off by default.)  * A **Totals by Product Code** section appears for each lot, after the **Fill** records and before the **Post-Fill** records.  * The grid shows the product code, description, and quantity filled. It also shows the volume filled if volume is displayed for assets on production records.### Enhancements* **TrackAbout Web » Order Scheduler**: The Order Scheduler has been updated to be even easier to use.  * **Order type icons and colors**: Deliveries, branch transfers, and maintenance orders each have their own icon and color throughout the scheduler.   * **Line item preview**: View an order’s line items in the **Order Details** dialog. A short preview also appears when you select a scheduled block.  * **Card and list views**: Switch the Orders panel between a card view and a compact list. The scheduler remembers your choice.  * **More unassigned orders**: The Orders panel now loads up to 200 orders at a time. A **Showing 200 of N** tag appears when more orders match your filters.  * **Duplicate holidays and blocked times**: Copy an existing holiday or blocked time to create a similar one without re-entering the details.  * **Branch transfer details**: Branch transfers now show the origin and destination branches.  * **Half-hour start times**: Orders that are scheduled automatically now start on the next half hour (for example, 8:30 AM instead of 8:20 AM).* **TrackAbout Web » TrackAbout Config**: You can now set the test date validation mode by asset type or product code.  * A **Last Test Date Validation Mode** list appears on the **Edit Asset Type** and **Edit Product Code** pages. The options are **Full Date**, **Year Only**, and **Month** **and** **Year Only**.* **TrackAbout Web » Customer Audit**: Exchange type balances can now be easily updated to match audited counts.  * **Audited Balance as of {audit date}** shows the customer’s physical balance based on the assets scanned in the audit.  * **New Current Balance** is the edited balance plus period-to-date ships, minus period-to-date returns.  * **New Rental Balance** is the new current balance minus Owned and Leased, never below 0.  * A **Total** row shows at the bottom of each grid.  * The audited column uses the most recent completed audit dated on or after the start of the last closed billing period. It’s blank if no audit qualifies.* **TrackAbout Mobile » Delivery Actions**: In the TrackAbout mobile app, you can now scan a barcode into the Purchase Order field instead of typing it. This reduces typing errors and speeds up delivery entry.  * A **Scan** icon appears in the Purchase Order field on the **Manual Order Entry** screen and on the standard **Delivery** screens.* **TrackAbout Web » Record Detail**: You can now see a record’s full verification history, including who unverified it, when, and why.  * Every unverify is now recorded in the record’s audit entries, whether a user does it or an edit does it automatically. Each entry shows who unverified the record, when, and the reason (if one was given).  * The **Unverify** popup has a **Reason (optional)** box, up to 1000 characters. A client setting can make the reason required.* **TrackAbout Web » Asset Agreements**: You can now see deleted asset agreements and restore them from the website.  * The **Modify Asset Agreements** permission must be enabled for you to delete and restore agreements.    * On the **Asset Agreements** page for a customer, select **Show deleted agreements** to include deleted agreements in the list.  * In edit mode, a deleted agreement shows **Restore** in place of **Delete**. Select **Restore**  to make the agreement active again.### Bug Fixes* **TrackAbout Mobile » Add New**: In TrackAbout Mobile, if you scanned a barcode that wasn’t recognized and then entered the key fields to identify the asset, the Choose Asset screen could show an empty list. This is now fixed.* **TrackAbout Web » Alerts**: Expiring asset alerts that matched thousands of assets could fail to send. They now send reliably.  * If an alert matches more assets than a limit (default 100 assets), the email lists only the first assets by soonest expiration date.  * The email also gives the total count and a link to the **Expiring Assets** report, where you can see the full list.* **TrackAbout Web/Mobile » Edit Assets**: After you edited an asset without touching a checkbox field, the record could show the checkbox value incorrectly. These checkbox and record issues have been resolved.* **TrackAbout Mobile » Delivery Receipt**: Receipts saved from iOS devices were missing the company logo and the delivery signature when you opened them from the website. They now include both items.
