# What's New: September 2026 Release Notes### New Features* **TrackAbout Web » Asset Families » Collision Resolution**: You can now enable the new Exclude from AI Collision Resolution setting for your account. When applied to a specific asset family, any collision involving that asset family will always require a manual review, even when automatic AI collision resolution is enabled. This feature is turned off by default. Contact TrackAbout Support to enable it for your account. Note the following:  * Once enabled, it defaults to No for every asset family; nothing changes until you opt a family in.  * If you don't use the automatic AI collision resolution feature, turning this on for a family has no effect, since nothing was being auto resolved to begin with.* **TrackAbout Web » Asset History:** The Asset History page now shows you when an entry has been modified or deleted, so discrepancies in an asset's history are easier to locate. This feature also applies to Valve History, for assets that track valve changes.* **TrackAbout Mobile » Scan Hard Goods:** You can now scan a hard good's package barcode directly on the Picking, Load Truck, Unload Truck, and Delivery screens, without opening Add Line Item to search for the product. This feature is off by default and turned on per client by TrackAbout Support. Your asset barcode formats must already be configured prior to using this feature.### Enhancements* **TrackAbout Web » Certificates of Analysis (COA) and Certificates of Conformance (COC)**: Certificates of Analysis (COA) and Certificates of Conformance (COC) are now available directly from the records that generated them, so that you don't have to search through asset histories to locate them.  * The certificate list on a record's page is now called Product Certificates and consists of a table with Certificate, Product Code(s), Lot Number, and Barcode(s) columns, instead of a list of download links.  * If a certificate's file is no longer available, its row shows "(Unavailable)" in muted text, and it's omitted from the ZIP file download.  * If you use the customer portal, a new Product Certificates section (showing a count, such as "Product Certificates (2)") appears on your Delivery records, listing only the certificates that delivery actually produced.* **TrackAbout Web » Rental Bills**: You can now filter and sort the Rental Bill Review page by servicing location, making it easier for each branch to review its own customers' bills before they're invoiced.  * A new Servicing Location filter is available in the search panel, offering All Locations (the default), Not Set, and your branch locations.  * A bill's servicing location reflects the branch that served the customer when the bill was generated. It doesn't change later, even if the customer is reassigned to a different branch afterward.  * The Servicing Location dropdown only shows branches you have permission to see.### Bug Fixes* **TrackAbout Web » Customer Rental Dashboard:** The Asset Agreements count on both the Rental Dashboard and the legacy Rental tab now reflects only agreements that are in force today — not every agreement that happens to still carry an Active status, including ones that expired years ago or were replaced by a renewal.* **TrackAbout Mobile » iOS Platform:** We resolved several issues that could cause the mobile app to crash on iOS; most often during extended scanning sessions, but also when navigating between screens or leaving a screen with the keyboard still open.* **TrackAbout Web » Post-Fill Analysis:** The Post-Fill Analysis screens now scroll completely on smaller-screen devices, so you can see, select, and complete every analyte instead of losing access to the bottom of the screen. This fix applies to Android devices only.* **TrackAbout Mobile » Maintenance with Work Orders:** When you're entering custom asset info (during Maintenance with Work Orders; Add New; or right after scanning an asset, including in Rack Fill) the form now scrolls with the keyboard open, so you can reach and see every required field. This fix applies to both Android and iOS.* **TrackAbout Web » Lot Reports:** We resolved an issue on the Lot Search report where the Quantity shown for a delivery could be under-reported once a lot's assets had since been moved to different locations, even though the delivery itself was correct and complete.
