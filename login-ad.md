# What's New: June 2026 Release Notes### New Features* **TrackAbout Mobile » Register Temporary Asset:** A new mobile action, Register Temporary Asset, is now available for registering customer-owned assets that arrive with only a customer-owned temporary tag and no permanent barcode. The action mirrors the existing Add New flow but is restricted to customer-owned temporary tags at both the first and final scan; permanent barcodes and return-only temporary tags are not accepted. * **TrackAbout Mobile » Electronic Notes:** TrackAbout Mobile now supports generating electronic notes, in compliance with Paraguay's SIFEN electronic invoicing system. When a driver completes a delivery on a Paraguay-configured Android device, TrackAbout automatically builds and submits the required dispatch document to the DPY Móvil app installed on the same device. DPY Móvil signs the document locally, generates a control code (CDC) and QR verification URL, and syncs with SIFEN when connectivity is available; no additional driver action is required.### Enhancements* **TrackAbout Mobile » Maintenance with Work Order / Maintenance at Customer:** When enabled by a new client configuration, the app now warns you when an asset being scanned was last processed under a different work order that is still open. A prompt identifies the previously recorded work order and the current one, and gives you the option to continue or cancel. Selecting Yes adds the asset to the current record and updates the stored work order number. Selecting No returns you to the scan step without adding the asset. No warning is shown when the asset has no prior work order recorded, when the stored work order matches the current one, or when the previously stored work order is already closed. This check applies to both Maintenance with Work Order and Maintenance at Customer. The warning is off by default and must be enabled per client.* **TrackAbout Mobile » Rack Fill**: When this configuration is enabled, the User field on the Production Record now lists every person who contributed to a fill (each user who paused the rack and the user who saved it) in chronological order. If the same person paused and saved, they appear once. This applies to both the Production Record web page and the exportable PDF. Regardless of the configuration setting, every pause event is now recorded as a Paused audit entry on the fill record, showing who paused it and when. When the configuration is disabled (the default), the Production Record continues to show only the user who saved the fill, as before.* **TrackAbout Mobile » Fill with Work Order**: The time required to load the work order list when starting a Fill with Work Order action has been reduced. Previously, retrieving available work orders could take approximately 15 seconds in some environments. Server-side processing has been optimized to return the list significantly faster.* **TrackAbout Web » Asset Families » Skip Lot Approval**: A new asset-family configuration, Skip Lot Approval, lets you keep the analysis step in place while removing the requirement to approve a lot from the Production Record page before assets become available for delivery. When this setting is on for an asset family, cylinders move directly to Ready for Use after analysis is recorded. No lot approval is needed, and assets are immediately available for delivery. The Certificate of Analysis is generated automatically at analysis time for affected asset families.* **TrackAbout Mobile » Fill with Work Order**: Administrators can now configure a date window that limits which work orders appear when an operator performs a Fill with Work Order action. When configured, only work orders whose Planned Fulfillment Date falls within the specified number of days before and after today are shown. Each work order in the list displays its Planned Fulfillment Date. If no work orders fall within the window, the operator sees a message indicating this. When no window is configured, all eligible work orders continue to appear as before.* **TrackAbout Web » Record Admin » Resolve Collisions**:  Resolve Collisions page has been redesigned to make it more efficient when working through a queue of collisions. The page has been updated to include the enhancements listed below.  * **Comparison Matrix**: Asset matches now appear in a side-by-side matrix with the incoming record. Each field row is color-coded: green when a candidate's value matches the incoming record, amber when it differs, and red for the fields that triggered the collision. (A checkmark or X icon accompanies each value for color-blind accessibility.)  * **View Toggle**: Filter the matrix to show All fields, Only differences, or Only collision cause to focus on what's relevant.  * **Inline Merge**: When you select two or more asset matches and choose Merge assets from the action bar at the bottom, a panel opens, enabling you to resolve any conflicting field values.  * **Queue Navigation**: A position indicator (for example, 1 / 4) shows where you are in the queue. Skip advances you to the next collision. Previous appears after your first skip and lets you return to the most recently skipped collision.  * **Asset History Dialog**: The Full asset history button opens an in-page dialog instead of a separate browser popup, so you stay on the collision you're resolving. Links inside the dialog open in a new tab.  * **Inline Activity**: A Show activity toggle below each asset match expands a view of that asset's recent history, centered on the collision time.* **TrackAbout Web » Setup » Barcode Range Rules**: Variable Length and Custom Prefix Now Supported: Barcode range rules now support variable-length barcodes and custom prefixes, giving administrators greater flexibility when configuring validation rules for different clients and barcode formats.### Fixes* **TrackAbout Web » Configured Jobs:** We resolved an issue where the Auto Renew Asset Agreements job did not renew agreements in certain scenarios when the job was configured to match the renewed agreement quantity to the holder's current rental balance.* **TrackAbout Web » Customers » Rental Dashboard**: For customers assigned to a rental rate bracket in environments that use tiered rental, the Rental Dashboard now correctly reflects the bracketed rate. Previously, when a customer had both a tiered standard rate and a bracketed rate, the dashboard could display a mix of standard and bracketed rate details or show the wrong rental method and rate values. The dashboard now consistently uses the bracketed rate when one is assigned to the customer.* **TrackAbout Mobile » Register Cylinder:** When using Save and Add More to register multiple assets in sequence, the asset family and ownership selections from the previous asset are now pre-populated for the next asset. Previously, both fields had to be re-entered manually for each asset even when they were the same.* **TrackAbout Web » Management Reports » Fill Report**: The Fill Report now includes unique assets that you attach to a fill record after the fact by using Attach by Barcode or Attach by Serial # on the record edit page. Previously, these assets were missing from both the Detail and Summary views of the report, even when the report date range covered the date the assets were attached. Assets added during the original mobile fill continue to appear as before, and non-scanned (quantity-only) rows are unaffected.* **TrackAbout Web » Management Reports » Production Record:** If your environment uses single sign-on (SSO), the re-authentication step for approving a production record is now more reliable. Previously, in some environments the approval could stall after you signed in successfully, leaving the approval button disabled even though authentication had completed. The sign-in popup now hands off to the parent page through a more direct mechanism, so the approval proceeds as soon as you finish signing in.
